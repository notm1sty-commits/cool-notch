# Cool Notch ✨

Превращает чёлку MacBook в живой мини-центр управления. Наведи курсор на вырез, и чёлка плавно раскроется.

## Что умеет

**В свёрнутой чёлке («живые активности» по бокам от выреза):**
- 🎵 когда играет музыка: обложка трека слева и «живой» эквалайзер справа в цвет обложки;
- ⚡️ при подключении зарядки: молния и процент заряда;
- 🪫 при низком заряде (20% и 10%): предупреждение;
- ⏱ во время таймера: кольцо прогресса и оставшееся время, а по окончании звонок «Готово!».

**В раскрытой чёлке (вкладки слева от выреза):**
- 🏠 **Главная**: плеер (обложка, перемотка ползунком, пауза и переключение треков) и таймер с пресетами на 1–45 минут;
- 🗂 **Полка**: перетащи файлы на чёлку, и они подождут здесь. Потом их можно вытащить в любое место, открыть двойным кликом или отправить по **AirDrop**: просто брось файл на синий круг;
- 📋 **Буфер обмена**: последние 30 скопированных текстов, клик снова копирует. Пароли не сохраняются;
- 📝 **Заметка**: быстрый блокнот, который сохраняется сам.

Справа от выреза показан заряд батареи и есть кнопка настроек. Иконка ✨ в строке меню открывает меню приложения.

Работает на macOS 14 и новее. На Маках без выреза рисуется «виртуальная» чёлка по центру строки меню.

## Как установить

1. Открой вкладку **Actions** в репозитории, затем последнюю успешную сборку **Build**. Внизу, в разделе *Artifacts*, скачай `CoolNotch-dmg`.
   После тега вида `v0.1.0` готовый `.dmg` появляется и в **Releases**.
2. Распакуй архив, открой `CoolNotch.dmg` и перетащи **Cool Notch** в папку «Программы».
3. Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS его заблокирует. Чтобы разрешить:
   - открой «Системные настройки» → «Конфиденциальность и безопасность», пролистай вниз и нажми **«Всё равно открыть»**;
   - или выполни в Терминале:
     ```bash
     xattr -dr com.apple.quarantine "/Applications/Cool Notch.app"
     ```
4. При первом треке macOS спросит разрешение управлять Spotify или Музыкой. Нажми **OK**.

## Сборка из исходников (на Маке)

Нужны Xcode 16+ или Command Line Tools.

```bash
./scripts/build-app.sh          # соберёт .build/app/Cool Notch.app и CoolNotch.dmg
swift run                        # быстрый запуск для разработки
```

Иконка рисуется скриптом `scripts/make_icon.py` (Python + Pillow) и лежит в `Resources/AppIcon.png`.

## Устройство проекта

```
Sources/CoolNotch/
  App/        запуск, меню в строке меню, настройки (UserDefaults)
  Window/     прозрачная панель над вырезом и отслеживание мыши
  Model/      NotchViewModel: открыта/закрыта, вкладки, живые активности
  Services/   музыка (AppleScript + MediaRemote), батарея (IOKit), полка, буфер, таймер
  Views/      весь интерфейс на SwiftUI
```

## Известные ограничения

- Начиная с macOS 15.4 Apple закрыла сторонним приложениям чтение «что сейчас играет» во всей системе. Поэтому название трека и обложка показываются для **Spotify** и **Музыки**. Кнопки play/pause и переключения треков, скорее всего, будут работать и с другими плеерами (например, с браузером), но без названия трека.
- Приложение подписано ad-hoc, поэтому после каждого обновления macOS может снова спросить разрешения.
